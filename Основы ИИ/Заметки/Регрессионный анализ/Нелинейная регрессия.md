# Дерево решений
В общем случае разделяет пространство на прямоугольные области. Рекурсивно делит данные, минимизируя дисперсию. Принцип работы: 
1) Начинается с корневого узла со всеми данными
2) Выбирается признак и пороговое значение, которое наилучшим образом разделяет данные.
3) Разделение данных на подмножества
4) Рекурсия!
Плюсы: такая модель не требует предположений о распределении данных. Такая модель может выполнять моделирование сложных нелинейных зависимостей. Может определять важное взаимодействие признаков. Минусы: склонность к переобучению. Данная модель нестабильна (малое изменение данных может существенно изменить дерево). 
# Метод опорных векторов для регрессии (SVR)
Выполняет SVM на задаче регрессии. Нахождение функции, которая отклоняется от исходной не более чем на дельту оставаясь как можно более плоской. Минимизирует норму весов при условии что ошибка лежит внутри некого пространства значений эпсилон. К особенностям метода следует отнести функцию потерь, не чувствительную к ошибкам, специфические подходы к нелинейным преобразованиям. Метод устойчив к выбросам. 
# Авторегрессионные модели
Использует предыдущее значение для предсказания. Будущее зависит от прошлого. Стационарны, автокорреляция, частичная автокорреляция.
1) Модель Олима. $Ar(p)$ - авторегрессия порядка p. $I(d)$ - интегрирование порядка d. $Am(q)$.
2) Векторная авторегрессия. VAR. Выполняет моделирование нескольких взаимсвязанных рядов, и каждый ряд зависит от предыдущих. Цены на связные товары, макроэкономические показатели. Требует определения оптимального датасета
