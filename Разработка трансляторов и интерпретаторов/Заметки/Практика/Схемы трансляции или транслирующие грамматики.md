Положим, есть грамматика, задающая выражения. И нам нужно получить ОПЗ из неё

$1. E -> E + T$
$2. E -> T$
$3. T -> T * P$
$4. T -> P$
$5. P -> (E)$
$6. P -> a_y$

В транслирующую грамматику добавляются ещё и символы трансляции. Для преобразования в ОПЗ например грамматика будет выглядеть вот так

$1. E -> E + T \{+\}$
$2. E -> T$
$3. T -> T * P$ \{\*\}
$4. T -> P$
$5. P -> (E)$
$6. P -> a_y \{y\}$

Запишем вывод, и в выводе будем учитывать и символы действия.

$E_2 => T_3 => T * P_6 \{*\} => T_3 * a_3 \{3\} \{*\} => T_4 * a_3 \{3\} \{*\} => P_5 * a_3 \{3\} \{*\} => (E_1) * a_3 \{3\} \{*\} =>(E+T_4 \{+\}) * a_3 \{3\} \{*\} => (E+P_6\{+\})*a_3 \{3\} \{*\} => (E_2+a_2 \{2\}\{+\}) * a_3 \{3\} \{*\} => (T_4+a_2\{2\}\{+\}) * a_3 \{3\} \{*\} => (P_6+a_2\{2\}\{+\}) * a_3 \{3\} \{*\} => (a_1\{1\}+a_2\{2\}\{+\})*a_3 \{3\} \{*\}$

Дальше мы должны поочерёдно освободить символы из скобок

12+3*

А теперь мы хотим получить 9. Пусть мы используем такую грамматику, чтобы получить ОПЗ. А чтобы вычислить значение, нужно просто вычислить значение из ОПЗ. Мы просто в качестве символов будем уже указывать непосредственно действия, а не символы. 

Теперь переведём в трёхадресный код. Он задаётся произвольно человеком. Есть два операнда и результат, и из таких операторов и составляется код. Например:

t_1 = 1 + 2
t_2 = t1 \* t3

Тогда первая скобочка будет набором действий

1. Написать t_{глоб. счётчик} = {взять из стека} + {взять из стека}
2. Положить в стек t_{глоб.счётчик}
3. глоб_счётчик++

Вторая будет 

1. Написать t_{глоб. счётчик} = {взять из стека} \* {взять из стека}
2. Положить в стек t_{глоб.счётчик}
3. глоб_счётчик++

А третья - 

1. Положить в стек просто значение

Алгоритмы можно оптимизировать. Например, в первой и второй скобке если оба операнда являются просто числами, можно вычислять эти числа на лету и складывать их в стек, чтобы не плодить переменные. 

Если оба операнда - переменные, результат можно записать в меньшую переменную.

Теперь переведём это в \*(+(1, 2), 3)

В первой скобке:

Положить в стек "\+({взять из стека}, {взять из стека})"

Во второй скобке

Положить в стек "\*({взять из стека}, {взять из стека})"

В третьей скобке

Положить в стек "{операнд}"
