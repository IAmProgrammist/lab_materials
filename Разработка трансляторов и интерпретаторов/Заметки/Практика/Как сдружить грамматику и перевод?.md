Положим, есть грамматика, задающая выражения. И нам нужно получить ОПЗ из неё

$1. E_x -> E_y + T_z$
$2. E_x -> T_y$
$3. T -> T * P$
$4. T -> P$
$5. P -> (E)$
$6. P -> a_y$
Положим, что мы знаем x и y. Тогда
1. x := yz+
2. x := y
3. x := yz*
4. x := y
5. x := y
6. x := y

Мы получили атрибутную грамматику. Найдём перевод для выражения

(1+2)\*3

Запишем для этого выражения вывод

$E_2 => T_3 => T * P_6 => T_3 * a_(3) => T_4 * a_(3) => P_5 * a_3 => (E_1) * a_3 =>(E+T_4) * a_3 => (E+P_6)*a_3 => (E_2+a_2) * a_3 => (T_4+a_2) * a_3 => (P_6+a_2) * a_3 => (a_1+a_2)*a_3$
