1. ОП -> if усл then ОП else ОП
2. ОП -> if усл then ОП
3. ОП -> оп

**Тест кейс 1:**

Исходный код:
```
if усл then
	<Оператор ДА>
else
	<Оператор НЕТ>
```

А надо получить будет

```
if not(усл) goto m1
<Перевод оператора ДА>
goto m2
m1:
<Перевод оператора НЕТ>
m2:
```

**Тест кейс 2:**
Исходный код:
```
if усл then
	<Оператор ДА>
```

А надо получить будет
```
if not(усл) goto m1
<Перевод оператора ДА>
m1:
```

1. ОП -> if усл {1} then ОП else {2} ОП {3}
2. ОП -> if усл {1} then ОП {3}
3. ОП -> оп {4}

Действия: 
	{1}: создать m
	 выдать if not(усл) goto m
	 положить в стек m
	 {2}: создать m2
	 выдать goto m2
	 из стека извлечь m1
	 выдать m1:
	 положить в стек m2
	 {3}:из стека извлечь m
	 выдать m:
	 {4}: выдать оп

Преобразуем грамматику в LL(1). Выполним левую факторизацию

1. ОП -> if усл {1} then ОП ОП' ВЫБОР=\{if\}
2. ОП' -> else {2} ОП {3} ВЫБОР=\{else\}
3. ОП' -> $\epsilon$ {3} ВЫБОР=\{else, конец\}
4. ОП -> оп {4}
