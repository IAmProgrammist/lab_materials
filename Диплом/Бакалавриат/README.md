# Оформление выпускных квалификационных работ БГТУ им. В.Г. Шухова в LaTeX

## Содержание проекта

1. Стилевой файл [bstunote.sty](bstunote.sty) устанавливает команды для форматирования выпускных квалификационных работ (ВКР) по требованиям кафедры программного обеспечения вычислительной техники и автоматизированных систем (ПОВТАС) БГТУ им. В.Г. Шухова. 
2. Файл [main.tex](main.tex) содержит титульные листы, утверждённые в БГТУ им. В.Г. Шухова, и методические указания к содержанию и оформлению ВКР. Файл [main.tex](main.tex) является одновременно и методичкой, и tex-шаблоном для написания самой ВКР.
3. [Заготовки](Заготовки/) с подключенным стилевым файлом [bstunote.sty](bstunote.sty), настроенные отдельно на компиляцию в PDFLaTeX, XeLaTeX или LuaLaTeX.

## Возможности
1. Поддержка компиляторов PDFLaTeX, XeLaTeX, LuaLaTeX. 
2. Рамки с чертёжными штампами согласно ГОСТ Р 2.104-2023.
3. Настроенные команды для форматирования заголовков, таблиц, листингов, списков, рисунков, оглавления, списка литературы, приложений.

## Сборка
1. Установить среду разработки [TeXstudio](<https://www.texstudio.org>) и дистрибутив [MiKTeX](<https://miktex.org/download>).
2. Открыть файл [main.tex](main.tex) в TeXstudio и скомпилировать.

## Условия использования

Проект направлен на продвижение издательской системы LaTeX в высших учебных заведениях. Распространяется под лицензией GNU GPL v3.
