### **1. Функциональная диаграмма (FDD / Feature Breakdown Diagram)**
**Проект: Система контроля для музыкальных продюсеров (Music Production Hub)**
- **1.0. Безопасность и управление доступом (Security & Access Core)**
    - 1.1. Аутентификация через Keycloak
    - 1.2. Управление глобальными ролями (User, Manager, Composer, Admin)
    - 1.3. Механизм проверки прав на уровне объектов
- **2.0. Управление контекстом (Context Management)**
    - 2.1. Управление проектами (создание, редактирование, обложка)
    - 2.2. Управление профилями авторов (ФИО, псевдоним, аватар)
    - 2.3. Приглашение участников в проект
- **3.0. Управление песнями и версиями (Song & Version Control Core)**
    - 3.1. Создание/редактирование карточки песни (название, описание, BPM)
    - 3.2. Версионное управление атрибутами песни
    - 3.3. Прикрепление файлов (аудио, изображения, другие) с версионностью
    - 3.4. Управление публичностью песни и отдельных версий
    - 3.5. Система комментирования (неверсионная)
- **4.0. Плейлисты и организация (Playlist & Curation)**
    - 4.1. Создание и управление плейлистами (публичные/приватные)
    - 4.2. Добавление в плейлист конкретной версии песни или ссылки на "последнюю"
    - 4.3. Фильтрация и поиск по плейлистам
- **5.0. Продвинутый аудиоплеер (Advanced Audio Workflow)**
    - 5.1. Базовый плеер (play/pause, next/prev)
    - 5.2. Параллельное воспроизведение нескольких треков
    - 5.3. Графический параметрический эквалайзер
    - 5.4. Индивидуальное управление дорожками ("продолжить с...", "стоп")
- **6.0. Пользовательский интерфейс (User Interface & Navigation)**
    - 6.1. Домашняя страница с виджетами (Проекты, Авторы, Плейлисты)
    - 6.2. Страница проекта с песнями и плейлистами
    - 6.3. Детальная страница песни с историей версий
    - 6.4. Страница плейлиста с встроенным плеером
    - 6.5. Страница автора
- **7.0. Интеграции и API (Integration & API)**
    - 7.1. Внутренний API для frontend (GraphQL/REST)
    - 7.2. Публичный API для интеграций (дистрибуция)
### **2. Диаграмма потока данных (DFD). Уровень 0 (Контекстная диаграмма)**
**Название:** Music Production Hub - Контекст  
**Основной процесс:** Система управления музыкальными проектами и активами  
**Внешние сущности:**
- **Пользователь (Менеджер/Продюсер):** Владелец процессов. Инициирует все основные действия.
- **Автор (Артист):** Источник метаданных (ФИО, псевдоним). _Примечание: Автор взаимодействует через Пользователя (менеджера)._
- **Keycloak (Сервис аутентификации):** Внешняя система, предоставляющая данные об аутентификации и пользователях.
- **Стриминговый сервис (будущий):** Внешняя система для экспорта финальных версий треков.
**Потоки данных:**
1. **От Пользователя к Системе:**
    - Запрос на вход / данные аутентификации -> **Система**
    - Команды управления (создать проект, добавить песню, создать плейлист) -> **Система**
    - Файлы (аудио, изображения) -> **Система**
    - Метаданные (названия, описания, BPM) -> **Система**
    - Команды плеера (play, pause, настройки эквалайзера) -> **Система**
2. **От Системы к Пользователю:**
    - Интерфейс (страницы, списки, формы) <- **Система**
    - Аудиопоток для воспроизведения <- **Система**
    - Уведомления, подтверждения <- **Система**
    - Отчеты об ошибках <- **Система**
3. **От/К Keycloak:**
    - Запрос на проверку токена -> **Keycloak**
    - Ответ с данными пользователя (id, роли) <- **Keycloak**
4. **От/К Стриминговому сервису (будущее):**
    - Экспорт трека и метаданных -> **Стриминг-сервис**
    - Статус публикации <- **Стриминг-сервис**

## **Модель данных**

### **1. ПОЛЬЗОВАТЕЛЬ СИСТЕМЫ (МЕНЕДЖЕР/ПРОДЮСЕР)**
- **ID** (уникальный идентификатор, синхронизируется с Keycloak)
- **Имя пользователя Keycloak**
- **Email**
- **Глобальная роль в системе** (один из: Пользователь, Менеджер, Композитор, Администратор)
- **Дата регистрации**
- **Связанные сущности**: Проекты (где имеет права), Плейлисты (созданные им), Комментарии
### **2. ПРОЕКТ / ГРУППА**
- **ID** (уникальный идентификатор)
- **Название**
- **URL обложки** (изображение проекта)
- **Создатель** (ссылка на Пользователя)
- **Дата создания**
- **Дата последнего обновления**
- **Связанные сущности**: Песни (основные), Песни-гости (из других проектов), Участники (с правами доступа)
### **3. АВТОР (МУЗЫКАНТ/ИСПОЛНИТЕЛЬ)**
- **ID** (уникальный идентификатор)
- **Полное имя** (реальное)
- **Псевдоним / Сценическое имя**
- **URL аватара** (фотография/логотип)
- **Описание** (биография)
- **Создатель записи** (менеджер, который добавил автора в систему)
- **Дата создания**
- **Связанные сущности**: Версии песен (где указан как автор)

### **4. ПЕСНЯ (МУЗЫКАЛЬНЫЙ ТРЕК)**
- **ID** (уникальный идентификатор)
- **Создатель** (ссылка на Пользователя)
- **Основной проект** (ссылка на Проект, где создана песня)
- **Дата создания** (первой версии)
- **Текущая актуальная версия** (ссылка на конкретную Версию Песни)
- **Связанные сущности**: Все версии песни, Комментарии
### **5. ВЕРСИЯ ПЕСНИ (версионные данные)**
- **ID** (уникальный идентификатор)
- **Песня** (ссылка на основную Песню)
- **Номер версии** (последовательный: 1, 2, 3...)
- **Статус** (Черновик, В разработке, Актуально, Архив)
- **Название версии**
- **Текст песни** (лирика)
- **Описание** (заметки о версии)
- **Темп (BPM)**
- **Флаг публичности** (видна ли эта версия в публичных плейлистах)
- **Автор версии** (кто из пользователей её создал/изменил)
- **Дата создания версии**
- **Связанные сущности**: Прикрепленные файлы, Связанные авторы, Связанные проекты-гости
### **6. ПРИКРЕПЛЕННЫЙ ФАЙЛ**
- **ID** (уникальный идентификатор)
- **Версия песни** (к какой версии прикреплён)
- **Тип файла** (Аудио, Изображение, Документ, Другое)
- **URL файла** (путь в хранилище)
- **Оригинальное имя файла**
- **Метаданные** (для аудио: длительность, битрейт; для изображений: размеры)
- **Загрузивший** (ссылка на Пользователя)
- **Дата загрузки**
### **7. КОММЕНТАРИЙ**
- **ID** (уникальный идентификатор)
- **Песня** (ссылка на Песню, не на версию!)
- **Автор комментария** (ссылка на Пользователя)
- **Текст комментария**
- **Дата создания**
### **8. ПЛЕЙЛИСТ**
- **ID** (уникальный идентификатор)
- **Название**
- **Описание**
- **Флаг публичности** (публичный/приватный)
- **Создатель** (ссылка на Пользователя)
- **Дата создания**
- **Дата последнего обновления**
- **Связанные сущности**: Элементы плейлиста
### **9. ЭЛЕМЕНТ ПЛЕЙЛИСТА**
- **Плейлист** (ссылка на Плейлист)
- **Версия песни** (конкретная версия, добавленная в плейлист)
- **Порядковый номер** (для сортировки в плейлисте)
- **Дата добавления**
### **10. ПРАВО ДОСТУПА К ОБЪЕКТУ**
- **ID** (уникальный идентификатор)
- **Тип объекта** (Проект, Песня, Плейлист)
- **ID объекта** (конкретного проекта, песни или плейлиста)
- **Пользователь** (кому выданы права)
- **Уровень доступа** (Зритель, Редактор, Владелец)
- **Кем выданы права**
- **Дата выдачи прав**
