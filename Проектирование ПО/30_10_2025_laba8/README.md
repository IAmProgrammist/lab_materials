Однако связное приложение, оптимизированное для решения конкретной небольшой задачи будет достаточно быстро справляться с задачей.                                                                                      | В целом, всё ещё немасштабируема. Разделение на слои позволяет в первую очередь масштабировать функционал приложения. В теории, будет работать медленнее, чем монолит из-за введения ограничений. | Предполагает введение нескольких независимых сервисов, довольно масштабируема. Масштабируемость горизонтальная. |
| Удобство использования | Крайне тяжело вносить изменения. Отсутствие ограничений предполагает введение структур данных, которые ссылаются и сильно зависят от друг друга. Одно маленькое изменение может затрагивать исправления во всём приложении.                           | Изменения вносить легче, так как задачи можно декомпозировать на слои. Изменения в задаче редко приводят к изменениям во всём приложении, а только в отдельных регионах.                          | Изменения вносить также лего. Микросервисы, работающие по одному интерфейсу, взаимозаменяемы.                   |
| Сложности разработки   | Подходит для разработки очень маленьких приложений с лёгкими задачами или решающих одну конкретную задачу. При решении большой задачи может привести к появлению невертикальных зависимостей, что усложнит разработку. Тестирование также затруднено. | Требует гораздо большего количества кода, который изначально может казаться ненужным. Проектирование тестов выполняется гораздо проще.                                                            | Требует введения дополнительной роли на проекте - девопс - для настройки интеграций между сервисами.            |

Текущий проект слишком мал для монолитной архитектуры, так как включает в себя множество задач, которые он будет решать. Микросервисная организация может потребоваться, например, для введения базы данных, S3, публикации в сервисы стриминга. Однако требуется развитая микросервисная инфраструктура, чем мы не обладаем. В итоге, наиболее подходящим является многослойная архитектура.
